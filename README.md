# Dotfiles

Configs for `~/.config`. The repository root **is** `~/.config`; app configs live directly at the root (`hypr/`, `alacritty/`, `tmux/`, `rofi/`, `firefox/`, `htop/`, `systemd/user/`, `dotfiles/`).

## Stack

- **OS:** Manjaro Linux
- **WM:** Hyprland
- **Notifications/OSD:** swaync + swayosd
- **Terminal:** Alacritty + tmux
- **Launcher:** Rofi
- **Shell:** Zsh
- **Editor:** Vim + vim-plug
- **Font:** Hack Nerd Font 15 (package `ttf-hack-nerd`)
- **Themes:** Everforest Light Soft / Gruvbox Green Dark

Hyprland uses `hypr/hyprland.lua` with modules in `hypr/conf/*.lua`. The legacy `hypr/hyprland.conf` is kept only as a reference.

## Install

### 1. Dependencies

```bash
sudo pacman -S --needed \
  hyprland swaybg hyprlock hypridle grim slurp \
  alacritty tmux vim zsh rofi nautilus \
  brightnessctl wl-clipboard papirus-icon-theme \
  ttf-hack-nerd git fastfetch bat swayosd jq swaync
```

Optional GUI apps (not required by any config):

```bash
sudo pacman -S --needed loupe obsidian
```

GTK themes are not in git. Put `Everforest-B-MB-Light` and `Gruvbox-Green-Dark` into `~/.themes` manually from GNOME Look.

### 2. Clone into `~/.config`

On a fresh machine where `~/.config` is empty:

```bash
git clone git@github.com:therealmaendeleo/dotfiles.git "$HOME/.config"
```

On a real machine `~/.config` already contains app data, so use:

```bash
git clone --no-checkout git@github.com:therealmaendeleo/dotfiles.git \
  "$HOME/.config-dotfiles"
mv "$HOME/.config-dotfiles/.git" "$HOME/.config/.git"
rmdir "$HOME/.config-dotfiles"
git -C "$HOME/.config" checkout -- .
```

Only tracked files are written; unrelated configs already in `~/.config` stay untouched.

### 3. Link home rc files

Shell and editor config lives in `config/` inside the repo and is symlinked into `$HOME` like `sobolevn/dotfiles`:

```bash
mkdir -p "$HOME/.vim/autoload"

ln -sfn "$HOME/.config/config/zshrc"    "$HOME/.zshrc"
ln -sfn "$HOME/.config/config/zshenv"   "$HOME/.zshenv"
ln -sfn "$HOME/.config/config/bashrc"   "$HOME/.bashrc"
ln -sfn "$HOME/.config/config/p10k.zsh" "$HOME/.p10k.zsh"
ln -sfn "$HOME/.config/config/vimrc"    "$HOME/.vimrc"
ln -sfn "$HOME/.config/config/vim/autoload/plug.vim" \
        "$HOME/.vim/autoload/plug.vim"
```

Reload the shell after this. `~/.gitconfig` is intentionally **not** stored in the repo; keep your local copy.

### 4. Link scripts

Scripts are stored in `bin/` and reached through the usual `~/.local/bin` paths:

```bash
mkdir -p "$HOME/.local/bin"
for f in "$HOME"/.config/bin/*.sh; do
  ln -sfn "$f" "$HOME/.local/bin/$(basename "$f")"
done
```

Other local binaries in `~/.local/bin` are left as they are and are not versioned.

### 5. Wallpapers

Wallpapers live in `media/`. Two tracked symlinks are checked out with the repo:

```text
hypr/wallpaper-light.jpeg -> ../media/wallpaper-light.jpeg
hypr/wallpaper-dark.jpg   -> ../media/wallpaper-dark.jpg
```

`switch-theme.sh` points the runtime-only `hypr/current_wallpaper.jpg` to the active one. That runtime symlink is ignored and is not stored in git. Hyprlock reads it for the lock-screen background.

### 6. Finish setup

```bash
systemctl --user enable --now \
  "$HOME/.config/systemd/user/AlacrittyAutoTheme.service"

vim +PlugInstall +qall

~/.local/bin/install-firefox-profile.sh
```

For a full Firefox migration, close Firefox first and run:

```bash
~/.local/bin/install-firefox-profile.sh --restore-all
```

`--dry-run` prints the actions without changing anything.

## Firefox snapshot

Portable parts of the active profile live under `firefox/`:

```text
user.js                     durable settings applied on every startup
prefs.js                    snapshot of the live profile with $HOME -> @@HOME@@
extensions.json             manifest with pinned sourceURI URLs
addons.json                 addon metadata
extension-preferences.json  extension permissions and origins
```

XPI binaries, `storage/`, logins, cookies and sync data are not stored. `user.js` is symlinked into the active profile by the install script.

## Alacritty themes

Only the two used colorschemes are tracked:

```text
alacritty/themes/themes/everforest_dark_soft.toml
alacritty/themes/themes/everforest_light_soft.toml
```

`alacritty/alacritty-auto-theme/theme.toml` is generated by the systemd service and is ignored.

## Rofi

`SUPER + D` runs `rofi-menu.sh`, which reads `hypr/current_theme_mode`:

- `light` → `rofi/colors/everforest_light_soft.rasi`
- `dark` → `rofi/colors/gruvbox.rasi`

Dark Rofi intentionally matches the GTK/system theme. Close and reopen Rofi after switching themes.

## Daily workflow

Helpers live in `dotfiles/helpers.sh` and are sourced from both `.zshrc` and `.bashrc`:

```bash
dotstatus                      # short status
dotuntracked                   # untracked files in key repo dirs
dotadd path/to/new/file        # stage a new file explicitly
dotsave "message"              # stage tracked changes, commit, pull --rebase, push
dotsave "message" new/file     # same, plus a new file
```

`dotadd` without arguments stages only already-tracked files. Helpers call `git -C "$HOME/.config"` directly; there is no `dotfiles` wrapper command anymore. Use plain `git -C "$HOME/.config" ...` for anything else.

## Deliberately not stored

Caches, browser/shell histories, generated theme files, runtime wallpaper symlink, plugin directories, GTK theme archives, Firefox profile databases, and any app config under `~/.config` that is not part of this setup.
