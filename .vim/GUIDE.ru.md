# Памятка по Vim: настройки и плагины

Открыть прямо из Vim: `:Guide`. Основной конфиг: `~/.vimrc`.
Плагины лежат в `~/.vim/plugged/`, управляются через **vim-plug**.

---

## 1. Что я поменял в `~/.vimrc`

- **Тема.** Теперь одна Everforest и для светлого, и для тёмного режима: мягкий
  контраст (`soft`) + курсив. Режим берётся из файла
  `~/.config/hypr/current_theme_mode` (там записано `light` или `dark`). Если сменить
  тему в Hyprland, Vim подхватит её при возвращении в окно (событие `FocusGained`).
- **Базовые удобства.** Номера строк, подсветка поиска, `ignorecase` + `smartcase`,
  отступ от края экрана (`scrolloff=8`), бесконечная отмена (`undofile`),
  `wildmenu`, новые окна справа/снизу, буфер обмена (`unnamedplus`).
- **Отступы.** «Мягкие табы»: 4 пробела почти во всех файлах. Исключение —
  `Makefile` и Go: там оставлены настоящие табы, иначе сломается сборка и `gofmt`.
- **Уборка.** Убраны лишние темы и неверная настройка `everforest_background='nature'`
  (правильные значения: `hard`, `medium`, `soft`).

Проверить текущее состояние можно так:

```
:set background?       " светлый или тёмный режим
:set tabstop? shiftwidth? softtabstop? expandtab?
:messages              " ошибки загрузки (если есть)
```

## 2. Какие плагины реально нужны

| Плагин | Решение | Почему |
|---|---|---|
| `sainnhe/everforest` | **оставить** | Активная тема, одна на оба режима. Других тем не нужно. |
| `junegunn/fzf` + `junegunn/fzf.vim` | **оставить** | Быстрый поиск файлов, буферов и текста по всему проекту. `fzf` — бинарник, `fzf.vim` — команды Vim; работают только вместе. |
| `tpope/vim-commentary` | **оставить** | Закомментировать/раскомментировать строку или блок одной командой. Очень нужно для скриптов и конфигов. |
| `tpope/vim-surround` | **оставить** | Обёртывание текста в кавычки, скобки, Markdown-жирный/код. |
| `wuelnerdotexe/vim-enfocado` | **удалён** | Ещё одна тема. Пока используем Everforest. |
| `sainnhe/gruvbox-material` | **удалён** | Ещё одна тема, дублирует функцию. |
| `chriskempson/base16-vim` | **удалён** | Фреймворк тем; без него конфиг проще. |

Если потом захотите попробовать другую тему, добавьте в блок `plug#begin` строку
`Plug 'имя/репозиторий'`, выполните `:PlugInstall`, затем `:colorscheme имя`.

## 3. Как пользоваться

### Базовые команды (без плагинов)

| Клавиши / команда | Действие |
|---|---|
| `i` / `Esc` | режим вставки / выход в обычный режим |
| `h j k l` | влево, вниз, вверх, вправо |
| `:w` / `:q` / `:wq` | сохранить / выйти / сохранить и выйти |
| `/слово` / `n` / `N` | поиск / следующее / предыдущее вхождение |
| `u` / `Ctrl+r` | отменить / повторить |
| `:%s/было/стало/g` | заменить во всём файле |
| `vim .` или `:Explore` | встроенный обозреватель файлов (netrw) |
| `:split` / `:vsplit` | горизонтальное / вертикальное окно |
| `:Guide` | открыть эту памятку |

### fzf — поиск (плагин)

```
:Files        найти файл по имени
:Buffers      переключиться между открытыми буферами
:Rg Word      найти Word во всех файлах (использует ripgrep)
:Lines        найти строку в текущем файле
:History      недавно открытые файлы
```

В списке: `Ctrl+j/k` — перемещение, `Enter` — открыть, `Esc` — закрыть.

### vim-commentary — комментарии

| Команда | Действие |
|---|---|
| `gcc` | закомментировать/раскомментировать текущую строку |
| `gcip` | комментарий для абзаца |
| `gc` + движение | комментарий для области, например `gcj` — текущая и следующая строки |
| визуальный режим → `gc` | комментарий выделенных строк |

### vim-surround — обёртывание текста

| Команда (курсор внутри слова) | Результат |
|---|---|
| `ysiw"` | `"слово"` |
| `ysiw*` (в Markdown) | `**слово**` — жирный |
| `ysiw` + символ обратной кавычки | `` `слово` `` — код |
| `csw"` | заменить `"слово"` на `'слово'` |
| `ds"` | удалить кавычки вокруг слова |
| выделить в visual → `S)` | обернуть выделение в `( ... )` |

### Отступы

- `Tab` вставляет 4 пробела (`expandtab`), `>>` / `<<` сдвигают строку.
- `:retab` — перевести уже существующие в файле табы в пробелы.
- В `Makefile` и Go файлах отступ остаётся настоящим табом — это специально.

### Тема

```
:colorscheme everforest   " перезагрузить тему вручную
:set background=light     " светлый вариант
:set background=dark      " тёмный вариант
```

Автосинхронизация с Hyprland уже включена: достаточно менять
`~/.config/hypr/current_theme_mode`, затем вернуться в окно Vim.

### Управление плагинами

```
:PlugInstall    установить из ~/.vimrc
:PlugUpdate     обновить
:PlugClean      удалить плагины, убранные из ~/.vimrc
:PlugStatus     посмотреть статус
:h surround     помощь по vim-surround
:h commentary   помощь по vim-commentary
:h fzf-vim      помощь по fzf.vim
```

---

## 4. Совет новичку

Не ставьте много плагинов сразу. Сначала освойте `h/j/k/l`, `w/b`, `:`, поиск `/`
и текстовые объекты (`iw`, `ip`). Из плагинов здесь реально полезны только четыре:
тема, поиск, комментарии и обёртывание — именно они и оставлены в конфиге.
